GameSinkid - Role System

บัญชีมี 2 ประเภท:
1. ผู้ใช้ทั่วไป: ดูเกม ค้นหาเกม และเพิ่มเกมในรายการโปรด
2. Developer: ฝากเกม ดูเกมของตัวเอง และดู Views / Clicks / Engagement

การใช้งาน:
- เปิด index.html ผ่าน VS Code + Live Server
- สมัครสมาชิกและเลือกประเภทบัญชี
- Developer สามารถกด + ฝากเกม และเผยแพร่เกม
- ทุกเกมเริ่ม Views/Clicks = 0
- เปิด detail.html จะเพิ่ม Views 1 ครั้ง
- กดเปิดลิงก์เกมจะเพิ่ม Clicks 1 ครั้ง
- ข้อมูลทั้งหมดเก็บใน localStorage ของ browser
